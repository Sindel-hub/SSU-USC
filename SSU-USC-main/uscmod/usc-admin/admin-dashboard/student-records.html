User Directory

Annual student import

Import an authorized SSU-USC list. Continuing students retain their Student ID, account, password, and activity history. Students omitted from a file are never automatically deactivated or deleted.

File requirements and accepted statuses

CSV or Excel (.xlsx), first sheet only, up to 500 students and 2 MB. Store Student IDs as text to preserve leading zeros. Use the template column names: studentId, fullName, department, program, yearLevel, email, status.

Use the official department and program names. Year levels: 1–6. Status: active, leave, inactive, graduated, transferred, withdrawn, or eliminated. A blank status means active. New accounts require an email; existing email changes need a separate verified process.
