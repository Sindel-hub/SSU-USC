Admin restrictions
  • Only accounts carrying the trusted admin server-side role may use this dashboard.
  • The admin account cannot access officer modules.
  • Student-linked records and activity are restricted to authorized administrators.

Annual student import

Import requirements

Import an authorized SSU-USC list. Continuing students retain their Student ID, account, password, and activity history. Students omitted from a file are never automatically deactivated or deleted.

Use the template for CSV or the first sheet of an Excel workbook. Store Student IDs as text. Use official department and program names and year levels 1–6.

Middle Name, Suffix, and Institution Email may be blank. SCL imports save academic records. Student Status may be Undergraduate, Active, Graduated, Dropped, or blank. Graduated and Dropped revoke linked account access. Normal imports never restore disabled access. Use Account Registration to issue an account.

Correct an earlier year / recover a test import

Upload the correct file and academic year. Access restoration requires Student Status Active or Undergraduate. Blank never restores access. Suspended, removed and pending-activation accounts stay blocked. School identity verification is not automatically restored.
