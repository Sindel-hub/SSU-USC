System policy

Sole admin identity

Administrator access is granted by a trusted server-side custom claim, not by a hard-coded email address.

Officer separation

The admin account is locked out of officer pages. Officers still use the officer dashboard and operational modules.

Recommended backend rule

Firestore rules should reject any write that attempts to assign role = "admin" to a different email.
